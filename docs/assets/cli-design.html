reble CLI output design

Every command opens with a ⎇ branch context line · cyan = branch · bold = table · +added −removed ~changed · dim = secondary · aligned gutters
$ reble status
⎇ fix-clv-returns
  created   2026-09-01 09:14 · ttl 14d
  writable  jaffle.customers
  pinned    jaffle.stg_customers, jaffle.stg_orders +4 more, frozen at epoch
$ reble branch create fix-clv-returns
⎇ main → fix-clv-returns
  scope  jaffle.customers                    inferred from your changes
  pins   raw.orders, jaffle.stg_orders +4     upstream inputs, frozen now
✓ switched to fix-clv-returns
$ reble branch create explore (branch-first, clean tree)
⎇ main → explore
  scope  open — grows when you edit models and run
  reads  every table frozen as of now (the branch epoch)
✓ switched to explore
$ reble branch list
  ⎇ main
● ⎇ fix-clv-returns   1 table · created 2h ago
  ⎇ explore           open scope · created 10m ago
$ reble run
⎇ fix-clv-returns
  changed    jaffle.customers
  published  jaffle.customers → branch ref
✓ 1 model in 0.4s
$ reble run (guard fires)
⎇ narrow
  changed    jaffle.stg_orders, jaffle.customers
  published  jaffle.customers → branch ref
⚠ jaffle.stg_orders changed but is outside this branch's scope — not published
  add it to the scope, or rethink the change
$ reble diff
⎇ fix-clv-returns vs base

  jaffle.customers            100 → 100 rows · key customer_id
    ~6 changed

  jaffle.fct_revenue          730 → 730 rows
    +20 added  −20 removed   no unique key: changes count as +/− pairs

  jaffle.mart_retention       new table — profile
    rows 52   cols cohort_week date · customers int64 · retained_w4 double 3 nulls
$ reble promote
⎇ fix-clv-returns → main
  ✓ jaffle.customers
⚠ pinned input raw.orders advanced on main while you worked — results used the older snapshot
✓ promoted · branch deleted · on main
$ reble load raw.orders seeds/orders.csv
⎇ main
✓ 300 rows → raw.orders (append)
$ reble diff (error: on main)
✗ on main — nothing to diff
  → switch to a branch first:  reble branch list
